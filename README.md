# R1 apps

Small creations for the Rabbit R1 (240x282 web pages).

- act/: side button cycles four pages: today's 3 must-wins (hold to speak one), focus timer, running pace and splits, voice notes. Data stays on the device.

- quiz/: Kids Quiz. Pick a topic and language (English/Russian); the R1 asks a question out loud, the child holds the button and answers, gets a kind check and a star; wheel = next.
- bits/: Bits, a Technology-lesson toy. Binary: 8 switches, wheel moves, tap flips, make the target number (levels go up). Ask: hold the button, ask a tech question, the R1 explains simply.

Install: open <app>/install.html and scan the QR code on the R1.
